# AssetRail v0.1.2

AssetRail v0.1.2 is a maintenance release of the offline, read-only withdrawal route planner.

## Changes

- Updates pinned React, testing, Vite, Tokio, time, UUID, serde_json, and error-handling dependencies.
- Refreshes transitive npm dependencies to clear the advisories reported against the v0.1.1 dependency graph.
- Preserves the existing offline fixture workflow, explicit provenance, and non-execution safety boundary.

## Distribution

The official macOS download is built from the tagged source commit, signed with the RSI Tech Developer ID identity, notarized by Apple, stapled, and published with a SHA-256 checksum.

## Limitations

AssetRail remains a read-only planning prototype. It does not submit withdrawals, move funds, or accept live exchange credentials.
