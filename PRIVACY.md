# Privacy

This policy describes the published AssetRail `0.1.x` source and the default
offline fixture build.

AssetRail does not collect, transmit, sell, or share personal data. The current
app has no account system, analytics, advertising, telemetry, crash upload,
remote configuration, live exchange connection, wallet connection, or hosted
AssetRail service. It does not persist user-entered route amounts after the
process exits.

The bundled planner data is synthetic. Destination tokens are deliberately not
valid wallet addresses, memos are absent, and financial values are invented for
deterministic tests.

Locally built development tools may produce ordinary compiler output and build
artifacts on the developer's machine. AssetRail does not receive those files.
GitHub processes repository interactions under GitHub's own terms and privacy
policy.

A fork that adds accounts, networking, persistence, analytics, crash reporting,
updates, purchases, or live financial data must publish its own accurate privacy
disclosures. Report a privacy or security concern privately through
[SECURITY.md](SECURITY.md).
