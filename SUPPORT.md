# Support

AssetRail is a prototype maintained on a best-effort basis.

Use [GitHub Issues](https://github.com/rsitech-ai/asset-rail/issues) for:

- reproducible defects in the offline fixture planner;
- build or setup problems using the documented pinned toolchains;
- narrowly scoped documentation or accessibility problems;
- feature proposals that preserve the read-only, no-credential boundary.

Include the AssetRail commit, macOS version, hardware architecture, exact
command, and redacted error output. Do not post credentials, private wallet
addresses, account data, or suspected vulnerabilities.

AssetRail does not provide financial advice, exchange support, account recovery,
wallet recovery, transaction execution, or guaranteed response times. Questions
about a fork or modified binary belong with that distributor.

Report security concerns through [SECURITY.md](SECURITY.md). Conduct reports use
the private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
